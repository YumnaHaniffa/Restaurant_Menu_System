## 📋 Project Overview

**To Vang** is a fully responsive, modern Vietnamese restaurant website that brings the authentic taste and warmth of Vietnam online.

Users can explore a beautifully designed menu, filter dishes by category and price, add items to cart, and complete a secure checkout — all built with pure **client-side technologies** (HTML, CSS, JavaScript & XML) as per the module requirements.

Designed with strong focus on **User Experience (UX/UI)**, accessibility, and clean code.

---
## ✨ Key Features

### Implemented from the Restaurant Menu Website Case Study:
- **Interactive Navigation Bar** with hover effects and consistent branding
- **Dynamic Menu** with real-time filtering by:
  - Category (Appetizers, Mains, Drinks, Desserts)
  - Price ranges
  - Meal preference (Veg / Non-Veg)
- **Add to Cart** functionality with live quantity update and total calculation
- **Order Form** with **6+ form elements** + custom JavaScript validation (no HTML5 validation)
- **XML Integration** – Menu data loaded dynamically from `menu.xml`
- **Gallery Page** showcasing restaurant atmosphere and dishes
- **About Us** and **Contact Us** pages with form validation
- **Responsive Design** across all screen sizes
- **Accessibility Features** (WAVE & axe tested)
